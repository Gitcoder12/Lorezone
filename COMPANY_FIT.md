# Lorezone — Company and Team Fit

Matches are prospective technical fit only, not product usage, customer status, endorsement or partnership.

## Project thesis

A website for browsing anime and manga, searching a catalogue and exploring related titles, franchises and timelines.

## Microsoft

**Relevant public technical areas:** Web platform security, cloud and developer tools.

**Potential roles:** Full-stack Engineer, Backend Engineer, Database Engineer, Application Security Engineer or Cloud Engineer.

**Evidence to build:** Next.js frontend, Express/TypeScript backend and PostgreSQL data model. It uses Jikan for live catalogue data and selected AniList enrichment, with database-backed title/franchise/timeline routes and account authentication. Issue #3 records unrestricted CORS and a weak fallback JWT secret; treat those as security blockers before public deployment.
